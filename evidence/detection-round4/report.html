Text and symbols: clutter experiments

No demonstrated improvement in this round. Two automatic repetition checks preserved the known labels but failed to remove the measured false positives. Neither is deployed.

Image evidence

Green boxes are candidates eligible for Top quality before density filtering. The false boxes in the background patch remain. Red would show a proposed demotion; none of these top candidates is demoted.

What was tested

First: high-pass patch matching to find repeated textures. Second: compare isolated component shapes so nearby contours do not dominate the match. Both use only map pixels and existing proposals. No place names, user markings, manual readings or reference boxes enter inference.

Where the clutter comes from

A read-only snapshot of current completed detector jobs contained 300 Top-eligible legacy symbol candidates and 423 Top-eligible character-region candidates. Coverage differs by detector, so those totals are not precision scores. They show why improving only text-region output cannot solve all visible clutter.

The next mark experiment should test richer synthetic hard negatives—repeated vegetation at variable sizes and contour intersections—alongside a separate small landmark proposal head. Keep unreadable glyphs as findings and recognition optional. Do not lower recall by forcing unknown shapes into a fixed symbol dictionary.
