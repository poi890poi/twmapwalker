# Mapwalker · Bô-chèng-siông / Rudy theme

Android installation page: https://poi890poi.github.io/twmapwalker/

This publication contains only the Mapsforge theme, resources, installation
instructions and checksums. The Rudy map and Mapwalker application data are not
included. Open the page on Android and tap **Install in OruxMaps**.

Based on Rudy / MOI.OSM Taiwan TOPO, Elevate by Tobias Kühn, and bochengsiong
by poi890poi. Theme modifications: Mapwalker. CC BY-NC-SA 3.0; resource-specific
licenses and full attribution are included in the ZIP.

OruxMaps documents the installation link in its official manual:
https://www.oruxmaps.com/OruxMapsManual-9.0_en.pdf

The ZIP uses the same XML and SVG assets as the desktop renderer. Device fonts,
DPI and placement can differ. Actual OruxMaps device rendering is not yet verified.
